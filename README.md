# uderia.com — the site

The published site of Uderia, a framework for trusted data agents. Generated from the
`trusted-data-agent-web` repository by `scripts/publish_pages.py`; edits are made there, never here.
Served by GitHub Pages at https://rgeissen.github.io/ (uderia.com by CNAME).

Repositories: [uderia-core](https://github.com/rgeissen/uderia-core) (the public core, Apache 2.0) ·
[uderia-enterprise](https://github.com/rgeissen/uderia-enterprise) (the enterprise package).
